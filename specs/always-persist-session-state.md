# Постоянное сохранение состояния сессии ViewPrint

## Контекст

ViewPrint сохраняет cookies и storage после команд автоматизации и при закрытии сессии. Однако cookies могут измениться асинхронно во время сетевых запросов страницы, после чего до следующей команды или закрытия процесса состояние ещё не записано на диск.

## Цель

Добавить фоновую синхронизацию состояния активной BrowserSession, чтобы текущие cookies, localStorage и sessionStorage регулярно сохранялись в `~/.viewprint/sessions/<name>/state.json` даже без новых команд CLI.

Сохранение должно выполняться best-effort: ошибка фоновой синхронизации не должна завершать браузерную сессию.

## Что изменится

1. `src/browser.ts` — запуск периодической синхронизации состояния после создания BrowserContext; корректная остановка синхронизации перед закрытием браузера.
2. `tests/browser.test.ts` — проверка, что cookie, добавленная непосредственно в Playwright-контекст, сохраняется на диск без вызова следующей команды BrowserSession.
3. `README.md` — описание гарантии и ограничений сохранения состояния.

## Детали реализации

1. После `BrowserSession.start()` запустить периодическую синхронизацию состояния с интервалом 1 секунда.
2. Использовать существующий `persistState()`, который получает актуальные cookies из BrowserContext и storage активной страницы.
3. Не допускать конкурирующих записей состояния: фоновые и командные вызовы должны выполняться последовательно.
4. В `close()` остановить таймер, дождаться последней записи и только затем закрыть BrowserContext.
5. Ошибки фонового сохранения логировать в stderr и не выбрасывать из таймера.
6. Зафиксировать, что сохранение не может защитить данные от `SIGKILL`, внезапного отключения питания или истечения/отзыва самих авторизационных cookies.

## Критерии приёмки

- [x] Cookie, изменённая страницей между командами, попадает в session state максимум через один интервал синхронизации.
- [x] Фоновая синхронизация не создаёт параллельных записей состояния.
- [x] При закрытии сессии таймер останавливается, а актуальное состояние сохраняется до закрытия браузера.
- [x] Существующие тесты, линтер и сборка проходят.
- [x] README описывает поведение и ограничения.
